# Personalization

Customize the actual Scrap League game: known preferred control scheme, assistance, sound/reduced-motion settings, car-preset names, team identity and scene styling where supported. Use confirmed user color/design preferences when requested; preserve readable HUD contrast and visible focus. Do not invent race history, unlocks, completed events or verified scores.

The twelve tracks, parts, cups, rivals and daily schedule are authored in content/ HTML. Preserve UUID references, required catalogs, closed-loop geometry, gates/grid, physics/comparison revisions and compiler constraints. Rebuild rather than edit generated content.json or meshes. Workshop can import/export canonical track HTML; its local drafts remain separate from immutable official tracks. Keep existing player/Workshop data and old Roundabout keys intact. No owner API token belongs in the game or personalization content.
