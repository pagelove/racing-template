# Installation and progress

The normal build parses authoritative content/ HTML and emits a complete current release under site/releases/sl-*/ plus site/index.html, sw.js and release.json. The derived JSON bundle is build output; geometry is authored/validated/exported as HTML. The old Roundabout implementation remains in Git history and its device-local keys are not imported or deleted.

IndexedDB uses pagelove-racing plus the installation directory, stable across immutable release IDs. Separate installations on one host have separate progress, presets, ghosts, results and Workshop drafts. A service worker controls only that directory; its cache name includes its registration scope. Range/query/stream requests and mutable Workshop/board resources are not served from this static cache.

The owner publisher uploads validated immutable dependencies and official content before index.html, verifies public identity, then derives the hosted worker/release inventory from the exact served entry bytes. This accounts for Pagelove serialization and its known branding footer without claiming arbitrary differences are safe. Local source inventory stays unchanged. Existing populated Workshop catalogs/tracks, boards, unrelated files and older release directories are never uploaded over or deleted by routine release publication. Official content changes are deliberate reviewed source releases, not Workshop mutations.

The game retains the upstream implementation boundaries in IMPLEMENTATION-STATUS.md. Browser-local state is not a shared server record or verified competitive score. Shared boards and remote Workshop publishing remain disconnected. No external account/provider is configured and no owner credential is collected by browser UI.
